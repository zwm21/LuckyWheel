# assets/fonts

此目录用于放置可选的内嵌字体文件（如 `HYWenHei-65W.ttf`）。

**仓库不包含任何字体文件**（字体版权归属原作者；`.gitignore` 全局排除
`*.ttf` / `*.otf`）。如需内嵌字体：

1. 自行获取字体文件，放入本目录，**文件名必须是 `HYWenHei-65W.ttf`**
   （运行时只按这个固定名查找，不扫描目录下的任意字体；名字不符时
   `build_exe.py` 仍会内嵌，但会显式警告"运行时不会被加载"）；
2. `python scripts/build_exe.py` 会自动检测并 `--add-data` 内嵌；
3. 程序按以下顺序查找：exe 解包目录 → 本目录（仅源码运行）→ 程序所在目录，
   均失败时回退为 Microsoft YaHei。打包后本目录不参与查找：解包目录位于
   `%TEMP%` 之下，任何用户态程序都可写，把仓库根候选留在它之前等于开放
   一个字体加载劫持面。

未放置字体不影响任何功能，仅界面与转盘文字使用回退字体渲染。
